# Claude Code adapter

Invoke the canonical workflow at `skills/improve/SKILL.md`. If project-local
skill discovery is configured, keep the adapter thin and point it to that file
instead of copying the workflow.

Optional delegation must follow the active agent instructions and available
tooling. Delegate only bounded evidence gathering or low-judgment mechanical
work. Keep decisions involving emulation behavior, libco scheduling, the public
C ABI, protocol changes, security/privacy boundaries, milestone claims, and
backlog or architecture updates with the primary agent. Do not run concurrent
builds against the shared `bsnes/obj/` directory.
